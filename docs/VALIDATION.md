# KumbhRakshak — Validation Rules

- **Phone Number**: Exactly 10 digits (`/^\d{10}$/`).
- **OTP**: Exactly 4 digits.
- **Full Name**: 2 - 100 characters.
- **Blood Group**: Enum (`A+`, `A-`, `B+`, `B-`, `AB+`, `AB-`, `O+`, `O-`, `Unknown`).
- **Age Group**: Enum (`18-30`, `31-50`, `51-65`, `65+`, ``).
- **Language**: Enum (`en`, `hi`, `mr`, `gu`, `sa`).
- **SOS Incident Payload**: Name & Location required.
- **Lost Person Report**: Name, age, gender, last seen location & guardian details required.
